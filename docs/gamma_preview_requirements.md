# Gamma 建模预览：Ti–V 对话复盘与迭代要求

日期：2026-10-16。状态：需求整理与源码审计；下述实现进展记录已落地的检查，其余条目仍为后续设计。

目标：让 `apex preview` 成为提交前可追溯的 Gamma 建模检查入口。用户应能确认用的是哪个 bulk、切了什么面、移动了哪些原子、位移是多少，以及模型是否满足本次计算协议。

## 本轮补充确认：界面成分与 fix_xy

来源：2026-10-16 当前对话，用户补充“小晶胞主要关注的是界面上的原子比例而不是随机摆放，还有需要fix xy去做gamma line的计算”。这两条列为 P0 要求。

- **小晶胞以断层界面局部成分为主要控制量。** 全胞 Ti/V 比例不能代替断层两侧的实际比例。建模先定义界面区域及目标元素计数，再安排该区域内的占位；随机种子只用于相同成分约束下的不同排布采样。不能仅随机生成全胞后，默认界面已达到目标成分。
- **界面区域必须可见且可复现。** 记录切面、上下两侧选入的原子层或法向距离范围、原子 ID、每侧和合计的 Ti/V 计数及原子百分比，并同时报告全胞成分。具体层数/窗口尚未指定，不能静默把某个窗口当作用户已确认的定义；可先展示逐层成分供选择。此处界面指内部滑移断层，不是外侧自由表面。
- **小晶胞目标比例受整数计数限制。** 对含 N 个原子的界面区域，目标比例必须落实为整数元素数；不可精确实现时，报告可实现比例与偏差，不得将近似值标成精确达标。不同局部排布仍可能影响结果，应保留构型身份，不能用一个随机种子证明成分效应。
- **Gamma line 各位移点必须采用 fix_xy。** 对本次局部 x/y 位于滑移面、z 为法向的模型，施加指定刚性滑移后，固定原子的 x/y 坐标，只允许 z 松弛，并固定晶胞形状和体积；u=0 与其他 u 点使用一致约束。bulk 可以有独立的 fix_xy/full-relax 协议，但不能据此把 Gamma 点改为 full relax。
- **约束必须核对实际任务输入。** preview 报告计划约束；任务生成后核对计算器输入是否落实同一约束。仅有参数声明不等于已经执行；若检查计算后轨迹，还应验证面内位移保持、晶胞不变。DPA 松弛后的 VASP 单点继续保持同一几何，不额外执行离子松弛。

## 实现进展（2026-10-16）

已实现 `apex preview` 自动输出 JSON/Markdown 检查报告，支持 `--check-only`、`--strict`、`--interface-layers`、`--interface-target`、`--composition-tolerance`、`--layer-tolerance`、`--export-structures`。已覆盖界面逐层/两侧成分与整数可实现比例、Gamma line fix_xy 配置、逐帧距离/位移/晶胞检查、源结构与参数哈希、全部 glob 匹配和独立结构导出。原子排序及 POSCAR 整体坐标反转均纳入映射。失败保留报告并返回非零；unknown 在 strict 模式下也阻止通过。

该版本检查生成几何及解析后的参数，不执行计算器，不证明历史 bulk 松弛或实际约束执行。连续轨迹、GIF 界面高亮/新视角、自动界面配比建模、自动整数正交超胞搜索仍未实现；本次通过明确的参数选择界面统计区域。refine/reproduce/start_confs_path 暂不支持来源追踪，显式拒绝。

### 需要纠正的历史技术表述

1. **指数变换必须遵守同一矩阵约定。** S2 的设计草案中有混用逆转置的表达，不能直接照抄。当前代码使用行矢量，`L_super = M @ L_parent`，因此 `d_super = d_parent @ inv(M)`，`h_super = h_parent @ M.T`。对 `M=diag(2,5,5)`、parent `(110)[−111]`，得到面指数比例 `(2,5,0)`、方向 `(-0.5,0.2,0.2)`；两者点积为零。验收应在 Cartesian 空间再次验证。
2. **局部 x 滑移不等于随意选择全局 x。** 正确的局部坐标应由 parent 滑移方向和法向生成；预览要把该变换解释清楚。slab 法向沿局部 z，与滑移沿局部 x 可以同时成立。
3. **RSS 的 u=1 不必化学闭合。** 应区分理想 parent 平移周期、忽略元素的几何匹配、保留元素的化学匹配，以及局部松弛造成的坐标偏差。不能要求所有随机合金经一个 parent Burgers 矢量后逐原子/逐元素重合。
4. **正交需求有适用范围。** Ti–V 本次协议要求正交；通用 Gamma 的合法面内斜胞不能一律判为错误。自动生成正交胞应采用保持周期性的整数超胞搜索，受原子上限约束，失败要解释。
5. **预览不能证明能量趋势。** 与目标曲线相似、单调递减、删掉某些 seed 后更接近目标，都不是几何正确性的验收标准。只采样 u=0/0.5 时应标为中点 GSFE；没有完整路径证据不能把它当作路径最大值。

## 3. 下一版 preview 的验收契约

### P0：可检查、可追溯、与正式任务一致

- 输出每个结构和性质的实际输入路径、SHA-256、formula、原子数、胞长/夹角、parent 类型、推断映射及匹配残差。bulk 松弛历史缺失时标记 unknown，不从目录名推断。
- 保存完整解析后的性质参数，区分用户值与默认值；明确是从输入 bulk 生成的未计算结构，还是已有任务的计算前/计算后结构。
- 对小晶胞报告界面区域定义、逐层及两侧合计元素计数、实际局部成分、目标偏差和全胞成分。显式目标未满足时不得标为协议通过；未定义界面区域时不得声称界面成分已验收。
- Gamma line 检查所有位移点的 fix_xy、法向松弛及固定晶胞设置，并分别标记计划配置、已生成输入与运行后验证的证据状态。
- 显示 parent 面与方向、映射后的指数、局部基、Cartesian Burgers 矢量、长度及单位；surface 还需两个独立面内位移基、夹角、采样范围和实际点数。
- 每帧保存 `(u)` 或 `(u,v)`、任务 ID、位移矢量、固定/移动原子 ID、计数、最小周期距离、原子数、晶胞与约束。元素排序后必须仍能追踪身份，不能直接套用排序前索引。
- 固定/移动分组在整条路径中不变；默认对称分割检查两侧数量，显式偏移切面则报告真实不平衡，不能不分情形强制 N/2。
- 报告材料法向周期厚度、沿法向原子跨度、外侧真空间隙、断层位置、断层两侧间距、总盒高、面积与界面数，各字段给出定义。设置 20 Å 不等于测得原子间边界空隙恰好为 20 Å。
- 严格正交协议检查 bulk 与 slab；bulk 不满足时阻止该协议，不能借 fix_xy 消除剪切。通用模式保留合法斜胞，同时明确实际夹角和坐标约束含义。
- 用生成器 metadata 决定位移与投影；不以 wrapped 相邻帧平均位移作为首选依据。周期 wrap、u=1、稀疏点不能误判滑移方向或“只有三层移动”。
- line 与 surface 使用同一诊断格式。结构错误输出非零退出码；警告保留警告；缺证据为 unknown。报告几何检查通过，不宣称能量收敛、模型准确或 slab 厚度已收敛。
- 全部 glob 匹配均被列出和处理；不存在匹配、重复输出、部分失败都明确报告。报告失败时也保留已获得的诊断。

### P1：让人工检查足够直观

- 保留默认双视角，新增滑移方向–法向侧视图，用来直接看材料厚度、真空和上下两块。slip-plane 视图看面内关系；parent-bc 视图保留与母结构的对应。
- 所有帧固定相机、比例尺与取景范围，允许切换“按元素着色”与“按移动组着色”；不能因逐帧自动居中造成虚假的整体运动。
- 显示断层面、方向箭头、u/v、Å 位移、移动/固定数目、材料/真空尺寸及明确轴标。默认只展示最关键标注，完整数值进报告。
- 高亮用于成分统计的界面原子，标注上下侧 Ti/V 计数及合计比例；提供逐层成分视图，使局部配比和占位排布都能直接检查。
- surface 增加二维采样网格与当前点高亮；蛇形顺序只影响播放，任务与采样数据保留原 ID。
- 导出初态、关键位移点及终点 POSCAR，连续 extxyz/LAMMPS dump；轨迹必须保留 ID、元素、晶胞与位移标签，必要时提供 wrapped/unwrapped 两种坐标。
- 同一批 seed/浓度生成汇总表，列出晶胞角、面积、厚度、原子数、协议与 parent 残差，帮助识别混入其他几何谱系的样本。

### P2：辅助构造符合要求的胞

- 增加保持晶格周期性的面内整数超胞搜索，兼顾正交性、原子上限和法向材料厚度；显示候选与代价。
- 当“指定原子数 + 正交 + 厚度”无同时满足的解时，给出冲突和可行候选，不能擅自扩成 1600–1800 原子，也不能拉伸晶格凑比例。
- Ti–V 的 100 原子 bulk、200 原子 slab、u=0/0.5、20 Å 真空作为个案回归配置，不成为全部材料的硬编码默认。

## 4. 目标输出与命令（部分已实现；实际用法见 README）

保留现有 `apex preview param.json`。新增选项可考虑 `--check-only`、`--report`、`--export-structures`、`--trajectory`、`--strict`；正交要求仍来自性质参数，避免 CLI 与参数文件出现两个冲突真值。

每个结构/性质输出独立目录：

```text
preview/<structure-id>/<property-id>/
  report.json                 # schema_version、来源、参数、检查、逐帧数值
  report.md                   # 人可读摘要与问题定位
  slip_plane.gif
  parent_bc.gif
  slip_normal.gif
  structures/                 # 保留真实生成文件及身份映射
  trajectory.extxyz
```

JSON 检查项建议包含 `code/status/message/frame_id/observed/expected/tolerance`；status 使用 pass/warn/fail/unknown。阈值必须有单位与来源。距离阈值沿用显式建模配置，不把曾经讨论的 1.7 Å 当作所有材料的安全值。

## 5. 必须覆盖的验收反例

| 用例 | 预期 |
| --- | --- |
| 两个小晶胞全胞 Ti 比例相同，界面 Ti 比例不同 | 分别报告局部比例，不把它们当作界面成分相同的重复样本 |
| 界面区域含12个原子，目标 Ti 为10% | 明确整数计数无法精确达到目标，报告候选计数对应的比例与偏差 |
| 同一界面比例、不同占位排布 | 保留不同构型身份，可比较排布效应，不自动认定能量相同 |
| bulk full relax，Gamma 点设置为 full relax 或允许盒子变化 | 本次 Gamma line 协议检查失败；要求 fix_xy、仅法向原子松弛且晶胞固定 |
| u=0 为 fix_xy，u=0.5 未设置同样约束 | 拒绝将该配对标记为协议一致 |
| BCC 2×5×5 RSS，parent (110)[−111] | 指数变换正确，Cartesian 滑移在面内，报告映射及实际半 Burgers 位移 |
| 旧 bulk 夹角约 85°，后续 fix_xy 保持晶胞 | 严格正交协议失败，不因“已松弛”或文件名正确而放行 |
| 合法斜胞，未要求正交 | 通过相应几何检查并展示夹角，不强行改胞 |
| vacuum 0 与 20 Å 的同一模型 | 明确区分材料与真空；加真空不改变材料内坐标距离；检查界面拓扑与归一化元数据 |
| 200 原子对称 slab；视图只看见三排 | 按真实 ID 验证移动分组，显示100/100（该用例），不能用可见排数推断 |
| 位移跨周期边界或只有 u=0/1 | 不丢失原子身份，不反转位移方向，不把周期闭合判作未滑移 |
| RSS u=1 化学不闭合 | 区分 parent 拓扑、几何、化学闭合，不能盲目 fail 或声称全部闭合 |
| surface 二维蛇形扫描、非等长位移基 | 各帧 (u,v) 与 Cartesian 位移一致，视角不随遍历方向改变 |
